# Archived Rust Service

This directory is a historical Rust v0.1.4 snapshot. Start with [ARCHIVE.md](ARCHIVE.md) for scope, provenance, and file locations.

For an explicitly requested change to archived Rust, apply the Rust conventions, context routing, and test guidance in [REPOSITORY_GUIDANCE.md](REPOSITORY_GUIDANCE.md). Its paths and commands are relative to this archive directory.

Preserve historical documents and release snapshots as references. Their milestones, technology choices, and proposed architecture do not define the Go rewrite. The standalone extension remains at the repository root.
