# NGA 监控

本上下文描述 NGA 内容监控、采集与通知中的核心业务概念。

## Language

**免拉取时段**：
监控目标保持启用、但不执行自动采集的周期性时间窗口；用户明确请求的手动运行不受其限制。
_Avoid_：静默时间段、通知静默

**免拉取跳过**：
自动运行因命中免拉取时段而在未采集新内容的情况下结束；它是正常的调度结果，不是成功拉取或运行错误。
_Avoid_：静默运行、免拉取失败

**手动运行**：
由用户明确请求的监控运行，不受免拉取时段限制。
_Avoid_：强制调度

**自动运行**：
由调度器发起的监控运行，命中免拉取时段时产生免拉取跳过。
_Avoid_：后台手动运行

**运行触发来源**：
运行记录所描述的发起方类别；新运行分为自动运行和手动运行，无法可靠追溯的历史运行使用“未知”。
