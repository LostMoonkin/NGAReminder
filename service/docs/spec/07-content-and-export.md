# 阶段 07：内容浏览、资源与导出

后续行为补充以 [Spec12：Rust 行为对齐与迁移补全](12-rust-parity-fixes.md) 为准。

## 目标

让已采集内容能够在管理页阅读，并导出为可保存、可离线查看的 Markdown 或 ZIP。
同时提供简单的本地资源管理，避免导出和下载留下无法处理的文件。

## 行为

- 管理页按主题和已监控用户浏览已保存内容，分页显示作者、时间、楼层、正文及来源链接。
- 用户内容只包含该 UID 已保存的帖子；按 TID 分组，不因浏览或导出额外抓取整个主题。
- 富文本与 Markdown 支持常用 NGA 格式：段落、强调、引用、代码、链接、图片和折叠内容；无法识别的标记保留可读文本。
- Web 富文本正确转义文本和属性，只输出允许的标签及安全链接，不直接插入原始 NGA HTML。
- 支持按 TID 和 UID 下载 Markdown；包含标题、作者、发帖时间、楼层/回复关系和原帖链接，顺序稳定。
- ZIP 包含 Markdown、`metadata.json` 和已下载的相关资源；包内使用相对路径，缺失或未下载资源保留远程链接。
- 资源下载可开关：开启时保存支持的图片/附件，关闭时保留元数据与远程地址；单个资源失败不影响正文保存。
- 下载只接受认可的 NGA 资源地址，检查响应类型和大小；生成的本地路径不得越过资源目录。
- 资源二进制落盘而非写入 SQLite；相同已保存资源可复用，不重复打包同一文件。
- 多页内容和资源以分批读写方式导出，避免把整份内容与资源同时载入内存；临时导出文件在完成或取消后清理。
- 管理页提供只读资源扫描，展示缺失文件、无引用资源和遗留临时文件；下载开启时可重新下载缺失资源。
- 管理员确认后才执行清理，默认只删除超过 24 小时且无引用的普通文件及临时文件，不跟随符号链接或删除仍被引用的文件。

## 约束

- 依赖 [阶段 03](03-user-monitoring-and-scheduling.md)，只导出数据库中已有的内容。
- 输出语义参考 [历史导出说明](../../../archive/rust-service/service/docs/EXPORT_RESOURCE_AND_CONTENT_UI_DESIGN.md)，不要求复刻其 AST 或导出实现。
- 内容转换采用共享的简单规则，避免 Web、Markdown、通知各自复制一套解析逻辑。
- 遵守 [服务端规范](../../AGENTS.md)；数据库与资源目录作为同一份业务数据保存和备份。

## 非目标

- 实时网页镜像、浏览器排版复刻、全文搜索平台和远程对象存储。
- PDF/Word 导出、异步导出任务平台及扩展插件改动。
- 自动清理已保存正文，或为了补全导出而扩大 NGA 抓取范围。

## 验收标准

- [x] 页面可分页浏览 TID/UID 内容；引用、代码、链接、图片和楼中楼关系可读且无原始脚本注入。
- [x] 多页样例的 Markdown 内容完整、顺序稳定；UID 导出只包含目标用户并正确分组。
- [x] ZIP 解压后 Markdown 可引用包内资源，缺失资源有源链接且不阻断导出。
- [x] 资源下载关闭或部分失败时正文仍可查看/导出，日志能定位资源失败原因。
- [x] 完成及中断导出后临时文件可被及时清理，异常退出遗留文件可通过维护操作处理。
- [x] 只读扫描不修改文件；用临时目录确认清理不会越界、跟随符号链接或删除仍被引用的文件。
