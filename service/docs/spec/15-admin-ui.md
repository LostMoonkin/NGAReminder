# 管理台 UI 重设计：B 方案

## 目标与已确认决策

用户 review 后选择 B 方案：顶部主导航、浅色背景、按状态分组的监控看板。解决原首页同时堆放账号、监控、内容、运行配置，以及各页面跳转方式不一致的问题。

原型保存在 `codex/ui-redesign-demo` 分支的 `fa300bf` 提交，路径 `service/web/prototype-ui/`。正式实现基于原有 Go 模板与服务端表单，原型切换条、A/C 布局、模拟数据和独立原型服务器均不进入正式版本。

## 页面与导航

所有页面共享顶部导航、当前位置、表单和按钮样式、移动端布局及错误反馈。

| 一级入口 | 路由与内容 |
| --- | --- |
| 运行概览 | `/admin`：真实监控/帖子/主题数量、监控看板、最近采集结果、账号与运行状态 |
| 监控管理 | `/admin/watches`：三列看板；`/admin/watches/new`：新建 TID/UID；原 `/admin/watches/:id`：详情 |
| 内容库 | `/admin/library`：主题列表；原 `/admin/users`：用户汇总；保留现有正文、分页、富文本与导出路由 |
| 收件箱 | `/admin/inbox`：全部消息、未读、待处理投递、系统告警；旧 `/admin/notifications` 仍可访问 |
| 通知渠道 | `/admin/channels`：Bark/飞书渠道及共享飞书应用 |
| 设置 | `/admin/settings`：NGA 账号；原续期、Bot、资源页面；`/admin/settings/runtime`：只读运行配置 |

- 页面导航、详情和外链使用链接；提交、运行、启停、测试、重试、导出使用按钮。新建入口明确标示为“新建监控”。
- 顶部导航在手机端横向滚动，看板变为单列，收件箱的消息目录与正文上下排列。
- 监控详情分为监控概况、采集配置、运行记录、历史回填/楼层补偿。保存配置回到配置标签；手动运行回到记录标签；历史回填回到回填标签。
- 删除监控、重建基线、删除渠道和撤销管理员绑定有确认步骤；保留服务端已有校验、权限与数据保留规则。

## 真实数据与行为

- 看板按“采集与待采集、免拉取时段、暂停与待处理”分组。手动暂停和认证暂停优先归入暂停列；正在运行的监控归入采集列；其余再按当前免拉取状态分组。
- 监控卡显示目标、备注、基础间隔、状态、水位和已有运行结果。不从原型复制总数、时间、收件地址或服务状态。
- 看板按 TID/UID 和名称/目标 ID 进行浏览器内筛选。内容库同样可筛选当前已加载的主题或用户。
- 未读及待处理投递先在数据库筛选，再按每页 50 条分页，避免只筛选当前页而漏掉旧事件。待处理包含 `pending` 和 `failed` 投递；同一事件有多个投递也只显示一次，已发送或已取消的投递不计入。
- 收件箱通过 `filter`、`page`、`event` 定位筛选、页码和当前消息。已读状态切换及投递重试保留此上下文；返回地址由服务端组合固定站内路径，不接受任意跳转 URL。
- 凭据仍不回显；飞书应用仍需点击“修改”才允许编辑，取消恢复原值，留空 Secret 保留原凭据。
- 运行或回填中允许自动刷新。进入配置标签、正在输入、存在未保存编辑或打开确认框时不会刷新页面；避免打断编辑。
- CSS/JS 随 Go 二进制嵌入，不依赖 CDN 或前端构建工具。JavaScript 仅增强筛选、标签、规则编辑和操作确认；普通链接和服务端表单仍为实际业务入口。

## 范围边界

不改变 NGA 采集、调度、通知匹配、Bot、续期协议、内容保留及资源处理规则。管理 API 的既有响应与鉴权保持不变；本轮筛选参数用于 Web 收件箱。未引入账号登录、Cookie 会话、独立 SPA 或前端依赖。

## 验收

- 顶部六个入口在所有管理页可达且高亮正确；原有功能均有明确归属。
- 实际完成监控创建、配置规则、暂停/恢复、取消/确认删除、渠道配置、收件箱已读切换及原有导出流程。
- 检查真实后台关闭、无凭据、空列表、免拉取、暂停、运行中、错误和分页状态。
- 桌面与手机页面没有整体横向溢出，表格在容器内滚动；禁用 JavaScript 后仍可浏览页面和提交基本表单。
- 运行既有 Go 检查；增加跨页消息筛选与受限返回路径的回归验证。浏览器核验使用独立临时数据库，不访问真实 NGA/飞书/Bark。

## 实现与核验记录

2026-09-20 已完成正式模板、嵌入资源和页面路由实现。原型保留在上述独立分支，正式页面使用现有业务服务和持久化数据。

- `gofmt`、`CGO_ENABLED=0 go build ./...`、`CGO_ENABLED=0 go vet ./...`、`CGO_ENABLED=0 go test ./...`、JavaScript 语法及 `git diff --check` 检查通过。
- 新增回归测试验证：未读和待投递事件先筛选再分页；多个投递不会重复消息；已读操作保留筛选上下文；返回地址受限于站内路径。
- Chromium 核验 21 个路由在 1440 px / 390 px 下的 42 个页面组合，无浏览器异常、失败响应或页面整体横向溢出。禁用 JavaScript 后，基础导航和监控配置仍可访问。
- 使用独立临时 SQLite 实测监控创建、调度规则保存、暂停/恢复、删除取消/确认、渠道增删/关闭、已读切换、飞书应用修改/取消、错误页及旧账号入口跳转。
- 实测运行中自动刷新及未保存输入保护；通过实际页面下载 Markdown 和 ZIP，并校验 ZIP 完整性。
- 预览关闭后台任务；此次未连接真实 NGA、飞书、Bark，也未执行线上部署。
