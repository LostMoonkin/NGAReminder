# Spec20：异步内容导出

## Goal

当前服务端保存的最大主题已超过 15 万楼，单次同步导出耗时较长，容易受浏览器或代理超时与连接中断影响，且导出完成后无法再次下载。

完成后，匹配帖子数超过默认阈值（10000 条）的导出请求自动转为后台异步导出任务。管理员和 API 调用方可在管理后台查看任务状态、在 7 天保留期内下载本地导出文件，过期文件由服务自动清理。

## Behavior

- 发起 TID 或 UID 的 Markdown/ZIP 导出时，按当次有效筛选条件统计快照范围内的已保存帖子总数：
  - 匹配条数不超过异步导出阈值（默认 10000 条）时，保持原有同步流式下载；
  - 匹配条数超过阈值时，自动创建持久化异步导出任务并在后台生成文件，请求立即返回，不阻塞当前 HTTP 连接。
- 异步导出任务记录目标类型与 ID、导出格式、筛选条件摘要、匹配帖子数、状态（排队/生成中、已完成、失败、已中断、已过期）、文件大小、错误信息、创建时间、完成时间与过期时间。
- 后台任务使用独立上下文与独立调用链执行，并关联发起请求的 `trace_id`；HTTP 客户端断开不中断导出。
- 后台异步导出采用有限并发（默认串行排队执行），避免多个超大导出同时争抢 SQLite 与磁盘 I/O。
- 异步导出生成的 Markdown 与 ZIP 保持与同步导出一致的内容排序、快照边界、Markdown 渲染、资源打包与缺失回退规则；导出仅读取本地已保存数据，不访问 NGA。
- 导出成功生成的文件保存在本地目录，默认自完成时间起保留 7 天；有效期内可多次下载，响应携带正确的文件类型与附件文件名，大文件下载不受普通 30 秒写入超时限制。
- 超过保留期的任务不再允许下载并返回明确提示；服务在启动时及运行期间定期清理过期的本地导出文件并更新任务状态。任务失败或中断时及时清理未完成的临时文件。
- 服务异常退出或重启时，启动阶段将遗留的排队或生成中导出任务标记为已中断，不自动重跑，用户可重新发起导出。
- 管理后台同步修改：
  - 保留 TID/UID 内容页的“导出内容”悬浮窗及无 JavaScript 基础表单；触发异步导出时跳转到导出任务页面并提示任务已创建。
  - 在「内容库」下新增“导出任务”视图，展示历史异步导出任务的目标、筛选条件摘要、格式、帖子数、状态、文件大小、时间、过期时间与错误信息；存在进行中任务时支持自动刷新（遵守现有输入与确认框防打断规则）；已完成且未过期任务提供下载入口，其余状态不提供下载。
- 管理 API 同步适配（沿用 Bearer token 认证）：
  - 现有导出接口在匹配条数超过阈值时返回 `202 Accepted` 及任务详情 JSON（含任务 ID、状态、查询路径与下载路径）。
  - 提供查询导出任务列表、查询单个任务详情与下载已完成导出文件的 API；任务不存在返回 404，任务未完成、失败、中断或已过期时返回明确状态与错误提示。

## Constraints

- 异步导出默认阈值 10000 条、默认文件保留期 7 天，均支持通过现有启动配置与 `NGA_REMINDER_` 环境变量覆盖（优先级沿用环境变量 > JSON 文件 > 默认值），未配置时使用默认值，并在运行配置页/API 展示生效值。
- 复用现有单机单进程、SQLite 与 `CGO_ENABLED=0` 运行模型，不引入外部消息队列、分布式调度或远程对象存储。
- 异步导出文件存储与 7 天保留期独立于资源维护页的 24 小时临时/无引用文件清理，不得被资源清理误删；文件读取与清理禁止路径越界和跟随符号链接。
- 复用 [阶段 07](07-content-and-export.md)、[Spec13](13-markdown-rendering.md) 与 [Spec16](16-time-ranged-content-export.md) 的导出格式与筛选规则，并沿用 [Spec15](15-admin-ui.md) 的原生模板、CSS 与渐进增强 JavaScript。
- 仅修改 Go 服务端与管理后台，不改动独立 Chromium 扩展。

## Out of Scope

- 为单次请求提供强制同步或强制异步的手动切换开关。
- 实时百分比进度条、取消运行中任务、HTTP 断点续传或重启后断点续导。
- 导出完成后的 Bark/飞书通知推送或定时计划导出。
- 为导出补抓 NGA 正文或下载缺失资源。

## Acceptance Criteria

- 匹配帖子数小于等于阈值（默认 10000 条）时，管理页与 API 继续直接返回同步下载文件，既有导出行为不变。
- 匹配帖子数超过阈值时，管理页提交后创建任务并跳转到导出任务视图，API 返回 `202` 与任务详情，不阻塞等待文件生成。
- 异步任务完成后，生成的 Markdown 与 ZIP 内容、排序、锚点及资源处理与同步导出一致；保留期内可重复下载且大文件下载不受 30 秒写入超时截断。
- 超过保留期（默认 7 天）后，任务不再允许下载，服务自动清理对应本地文件；资源维护页的 24 小时清理不会误删未过期的异步导出文件。
- 服务重启时遗留的排队/生成中导出任务标记为已中断并清理未完成临时文件；失败任务记录可读错误并在日志中保留完整错误堆栈。
- 管理后台「内容库」可查看导出任务列表与状态，进行中任务可自动刷新；桌面与手机端无整体横向溢出，禁用 JavaScript 仍可发起导出并查看/下载任务。
- `node --check web/static/admin.js`、`CGO_ENABLED=0 go build ./...`、`CGO_ENABLED=0 go vet ./...`、`CGO_ENABLED=0 go test -count=1 -timeout=30s ./...` 和 `git diff --check` 通过。
